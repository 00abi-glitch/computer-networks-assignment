# Assignment

Assignment 3

## Title

Data-Link Layer, Ethernet and Wireless LANs

## Objective:
Our primary goal is to analyze the core functions of the data-link layer—specifically framing, MAC addressing, and shared-media access protocols. We focus heavily on the mechanics of Ethernet, Wireless LANs (WLANs), and Mobile IP technologies.

## Solution:
We addressed each requirement by providing detailed theoretical explanations, structured comparison tables, and illustrative diagrams. Our analysis covers the foundational data-link layer duties, Ethernet frame structures, dynamic switch MAC learning, and the functional differences between hubs, bridges, and switches. Furthermore, we detailed the shift from CSMA/CD to CSMA/CA, engineered a practical WLAN design for a laboratory, mapped out Mobile IP architecture, and compared the structures of wired versus 802.11 frames.

## Output:
Our final deliverable is a comprehensive PDF document that includes an Ethernet frame breakdown, a step-by-step switch forwarding scenario, a proposed WLAN topology, a Mobile IP flow diagram, and side-by-side technical tables. Please note that we intentionally omitted the Wireshark packet captures, as Question 3 was excluded from our scope.

## Conclusion:
Through this assignment, we concluded that modern, switched full-duplex Ethernet has rendered CSMA/CD largely obsolete. Conversely, the chaotic nature of wireless environments still mandates the active use of CSMA/CA and a significantly more complex 802.11 frame structure. Additionally, we demonstrated that Mobile IP remains a critical mechanism for maintaining persistent network connections as devices roam across different physical locations.
